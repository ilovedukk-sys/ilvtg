# ilvtg

Неофициальный клиент Telegram для iPhone с упором на приватность и экономию ресурсов.

ilvtg — самостоятельный проект. В репозитории только наш код: Swift-модули в `src/` и скрипт
`ci/prepare.py`, который накладывает наши правки на **официальный** исходный код
[Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) (коммит закреплён в
`upstream.json`). От сторонних форков сборка не зависит. Идеи частично взяты у
[VoidGram](https://github.com/neosay-dev/VoidGram), но их код здесь не используется.

## Что изменено

Все настройки собраны в отдельном пункте **Настройки → ilvtg** (с вишнёвой иконкой призрака): сверху иконка, название и версия, ниже категории — «Режим призрака», «Шпион», «Голос и кружки», «Оформление», «Безопасность», «Инструменты» — каждая открывает свою страницу.
Тот же экран открывается из Настройки → Конфиденциальность → «Приватность ilvtg».

### Режим призрака
Общий переключатель «Режим призрака» включает сразу все опции, каждую можно включить и
отдельно. По умолчанию все выключены.

| Опция | Что делает |
|---|---|
| Не отправлять «прочитано» | не отправляет `messages.readHistory`, `channels.readHistory`, `messages.readDiscussion`, `read*MessageContents`, `readEncryptedHistory` |
| Смотреть истории незаметно | не отправляет `stories.readStories`, `stories.incrementStoryViews` |
| Не показывать «в сети» | вместо «в сети» приложение каждые 30 секунд сообщает «не в сети» (`account.updateStatus(offline: true)`). После отправки сообщения, реакции или голоса в опросе сервер сам ставит «в сети», поэтому сразу после такого запроса (через 0,4, 1,5 и 4 с) приложение снова сообщает «не в сети» — отметка держится доли секунды |
| Не показывать «печатает…» | не отправляет `messages.setTyping`, `messages.setEncryptedTyping` |

**Призрак для отдельного чата.** В шапке каждого чата рядом с аватаркой есть кнопка с
призраком. Она включает или выключает режим только для этого собеседника: «прочитано»,
«печатает…» и просмотры его историй. Например, для одного человека вы невидимы, а для другого
нет. Выбор для чата важнее общих переключателей. Сбросить выбор во всех чатах можно на
экране ilvtg, а скрыть саму кнопку переключателем «Кнопка призрака в чатах».

Ограничения: если вы отправите сообщение в чат, сервер Telegram всё равно отметит его
прочитанным. После выключения режима следующее прочтение подтвердит и все предыдущие сообщения.
Telegram считает такие функции нарушением [API ToS](https://core.telegram.org/api/terms),
поэтому используйте их на свой риск.

### Сообщения (по умолчанию включено)
- **Удалённые сообщения сохраняются.** Если собеседник удалил сообщение, оно остаётся в чате,
  а рядом со временем появляется пометка «удалено». Работает для сообщений, которые уже были
  загружены на устройство.
- **Самоуничтожающиеся сообщения сохраняются.** Таймер не удаляет сообщения и не стирает медиа
  (в том числе в секретных чатах и чатах с автоудалением).
- **Одноразовые без ограничений.** Одноразовые фото, видео, голосовые и кружки можно открывать
  сколько угодно раз. Приложение не отмечает их просмотренными, поэтому отправитель не узнает,
  что вы их открыли.

### Голосовые и кружки
- **Изменение голоса:** «ниже», «намного ниже», «выше», «намного выше». Голос меняется при записи
  голосовых сообщений и кружков, длительность не меняется.
- **Замазывание лиц в кружках** (по умолчанию выключено): перед отправкой лица в каждом кадре
  находятся встроенным распознаванием iOS (Vision) и пикселизируются. Обработка занимает
  несколько секунд и идёт только на устройстве.
- Пока включена хотя бы одна из этих функций, кружок загружается только после окончания записи,
  чтобы на сервер не попала необработанная версия.

### Из AyuGram (без сторонних серверов)
- **Отправка без выхода в сеть** (по умолчанию включена, работает вместе с «Не показывать «в сети»»):
  сообщение уходит как отложенное на 12 секунд, сервер публикует его сам и не отмечает вас в
  сети. Пока сообщение не опубликовано, оно лежит в «Отложенных».
- **Отметить чат прочитанным** в режиме призрака: долгое нажатие на сообщение → пункт меню.
  «Прочитано» уходит один раз по вашему желанию, режим остаётся включённым.
- **История изменений:** если собеседник изменит сообщение, прежние версии сохраняются (файл в
  защищённом контейнере приложения). Долгое нажатие → «История изменений».
- **Обход запрета копирования:** в чатах и каналах с «Запретом копирования» можно копировать
  текст, сохранять медиа и делать скриншоты. Пересылка оттуда тоже работает: сообщение уходит от
  вас как новое, а фото, видео, голосовые, кружки и файлы скачиваются и загружаются заново
  (альбомы остаются альбомами).
- **Скриншоты не отслеживаются:** собеседник не получает уведомление о скриншоте секретного чата
  или одноразового медиа.

### Оформление
- **Вишнёвый цвет интерфейса** (по умолчанию включён) вместо стандартного синего во встроенных
  темах. Если в «Оформлении» выбран другой цвет, остаётся он. Применяется после перезапуска.
- **Прозрачность сообщений:** 100, 85, 70, 50 или 30 % непрозрачности пузырей (после повторного
  открытия чата).
- **Панель вкладок:** можно скрыть вкладки «Контакты» и «Звонки» и подписи под иконками.

### Профили
- **ID в профиле** (по умолчанию включено): строка «ID» в профиле пользователя, группы или канала,
  нажатие копирует. Для групп и каналов ID в формате Bot API (`-100…`).
- **Режим стримера:** номера телефонов, юзернеймы и ID в профилях показываются точками, нажатие
  открывает значение. Номер и юзернейм в шапке «Настроек» скрыты, пока режим включён.

### Эмуляция геопозиции
Вложения → «Геопозиция» → передвиньте карту так, чтобы метка стояла в нужной точке → «Эмулировать
геопозицию здесь». Пока эмуляция включена, приложение сообщает эту точку вместо настоящей:
«Отправить моё местоположение», трансляция геопозиции и всё, что берёт координаты устройства.
Выключить — той же строкой в окне геопозиции или в Настройки → ilvtg.

### Фейк-пароль
Настройки → ilvtg → «Задать фейк-пароль…». Работает вместе с код-паролем приложения: если на
экране блокировки ввести фейк-пароль, все аккаунты завершаются на сервере, данные на устройстве
стираются, и приложение открывается уже без аккаунтов. Можно выбрать «Удалить аккаунты
навсегда» — тогда перед выходом аккаунт Telegram удаляется (`account.deleteAccount`) без
возможности восстановления. Фейк-пароль должен быть того же вида, что и настоящий (например,
4 цифры), и отличаться от него.

### Экспорт чата
Настройки → ilvtg → «Экспорт чата…» → выберите чат. Вся история скачивается и сохраняется в
текстовый файл (дата, автор, текст, тип вложения). Файл можно сохранить в «Файлы» или отправить.

### Всегда
- **Телеметрия не отправляется:** `help.saveAppLog` (журнал событий приложения),
  `phone.saveCallDebug` и `phone.saveCallLog` (отладочные логи звонков).
- **Реклама в каналах и промо-канал прокси** не запрашиваются (переключатель, по умолчанию включён).

### Приватные настройки по умолчанию
- Синхронизация контактов выключена, в том числе сразу после входа (включается в
  Конфиденциальность → Настройки данных).
- CallKit выключен: звонки не попадают в «Недавние» iOS и в iCloud.
- Чаты и контакты не передаются в Siri, Spotlight и подсказки меню «Поделиться».
- Входящие сообщения не передаются в Siri.

### Оптимизация
- Release-сборка arm64 без dSYM.
- Без расширений (виджет, Siri, «Поделиться», уведомления, демонстрация экрана): IPA меньше,
  а при sideload нужен один App ID вместо семи. Вернуть их можно через `app_extensions: true`
  в `app.json`.
- Через сотовую сеть по умолчанию стоит профиль автозагрузки «низкий».

Как это работает: все запросы MTProto проходят через `Network.request`. Правка
`network-guard` не отправляет телеметрию и запросы рекламы. Запросы режима призрака зависят от
чата, поэтому каждая из 22 точек отправки «прочитано», «печатает…» и просмотров историй вызывает
`Network.ilvGhostRequest` с идентификатором чата (правки `ghost-*` в
[`ci/prepare.py`](ci/prepare.py), логика в
[`src/TelegramCore/IlvPrivacy.swift`](src/TelegramCore/IlvPrivacy.swift)). Все эти точки
обрабатывают ошибку без повторов, мы проверили это на закреплённом коммите.

## Сборка в GitHub Actions

1. Получите `api_id` и `api_hash` на <https://my.telegram.org/apps>.
2. Добавьте их в секреты репозитория (Settings → Secrets and variables → Actions):
   `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Без них приложение соберётся, но войти не получится.
3. Сборка запускается при каждом push в `main` (или вручную: Actions → iOS build → Run workflow).
   Сначала около 2 минут идёт проверка того, что все правки применяются, затем полная сборка
   на раннере `xcode-27` (macOS 27, Xcode 27.1), она занимает 1,5–3 часа.
4. Готовый `ilvtg.ipa` появится в артефактах запуска (хранится 7 дней).

## Установка на iPhone

IPA **не подписан**. Установить его можно так:
- [Sideloadly](https://sideloadly.io/) или AltStore/SideStore с бесплатным Apple ID
  (приложение придётся переподписывать каждые 7 дней);
- платным сертификатом разработчика;
- через TrollStore, если ваша версия iOS его поддерживает.

Инструменты sideload при переподписи часто убирают entitlement App Group. Официальный Telegram
в этом случае зависает на чёрном экране. ilvtg тогда хранит данные в собственной папке внутри
песочницы приложения (Application Support, исключена из бэкапа iCloud). Код-пароль на экран
блокировки в такой установке может не сохраняться, потому что связке ключей тоже нужна App Group.

Push-уведомления в самостоятельно собранной версии не работают: Telegram отправляет их
только на сертификат официального приложения. Пока приложение открыто или работает в фоне,
сообщения приходят.

⚠️ `api_hash` зашит в IPA. В публичном репозитории артефакты может скачать любой
пользователь GitHub, поэтому не раздавайте сборки посторонним.

## Локальная сборка (macOS)

```bash
git clone https://github.com/TelegramMessenger/Telegram-iOS.git telegram
git -C telegram checkout $(python3 -c 'import json;print(json.load(open("upstream.json"))["commit"])')
python3 ci/prepare.py telegram
git -C telegram submodule update --init --recursive --depth=1
bash ci/macos_setup.sh telegram
TELEGRAM_API_ID=... TELEGRAM_API_HASH=... python3 ci/build.py telegram --cache-dir ~/.ilvtg-cache --out out
```

## Обновление базы Telegram

Поменяйте `commit` в `upstream.json` и запушьте. Если какая-то правка перестанет совпадать
с новым кодом, задача `patches` упадёт с именем правки и файлом. Исправьте фрагмент в
`ci/prepare.py`.
